# Изгиб Питона

Классическая «Змейка» на Python и Pygame. Игровые объекты описаны
классами `GameObject`, `Snake` и `Apple`.

## Запуск

Требуется Python 3.10 или новее. В PowerShell из каталога проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe the_snake.py
```

Управление — стрелки клавиатуры. Для выхода закройте окно.

Поле размером 640 × 480 пикселей состоит из клеток 20 × 20 пикселей.
Змейка начинает движение вправо и проходит через границы поля.
Красное яблоко увеличивает её на один сегмент; яблоки появляются
только в свободных клетках. Столкновение с собой перезапускает партию.
После заполнения всего поля также начинается новая партия.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe -m flake8
```

Тесты используют виртуальный экран SDL и не открывают игровое окно.
